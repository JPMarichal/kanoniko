## Convergencias entre ramas

```
2000 a.C.    1000 a.C.   500 a.C.    1 d.C.     400 d.C.    1820 d.C.
  │             │           │          │           │           │
  A1─A2─A3─A4─A5─A6──A7──A8─A9─A10─A11─A12─A13─A14─A15──────┐
                                                             │
  B0a─B0b─B0c ──┤                                            │
                B1──B2──B3──B4──B5──B6──B7──B8──┐            │
                                                 │            │
                    C1──C2──C3──C4───────────────C5───────────C6
```

Convergencias clave:
- A15 (intertestamentario) → C1 (Vida de Cristo)
- B6 (Cristo en las Américas) converge con C1/C2 — mismo Cristo en dos continentes
- B termina en 421 d.C., durante C3 (apostasía progresiva)
- C continúa sola después de 421 d.C.

## Notas de diseño

- **No es monolineal:** las tres ramas corren en paralelo y convergen.
- **Rama A está cerrada y aprobada.**
- **Ramas B y C:** pendientes de definición final.
- Este esquema es la **raíz** — de él cuelgan subcronologías detalladas por
  periodo y esquemas de eventos.
