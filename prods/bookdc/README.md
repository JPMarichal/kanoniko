# Libro sobre Doctrina y Convenios - Material Preparatorio

Este directorio contiene el material completo y organizado para la preparación de un libro sobre Doctrina y Convenios (DyC), incluyendo biografías de personajes, esquemas de perícopas, referencias documentales y herramientas de investigación.

## 📁 Estructura del Proyecto

### `contenido/`
Material principal y contenido final del libro.

- **`biografias/`** - 135 biografías completas de personajes mencionados en DyC
- **`pericopas/`** - 138 esquemas textuales de las secciones de DyC  
- **`graficos/esquemas/`** - 138 archivos PNG con esquemas visuales (esquema_dyc_XXX.png)
- **`graficos/personajes/`** - 140+ archivos PNG con diagramas de personajes por sección (personajes_dyc_XXX.png, personajes_od_XXX.png)
- **`datos/`** - 140+ archivos JSON con resúmenes estructurados por sección (sumario_dyc_XXX.json)

### `referencias/`
Documentación de referencia y fuentes consultadas.

- **`fuentes.md`** - Catálogo maestro de fuentes bibliográficas
- **`matriz_de_fuentes.md`** - Matriz operativa de fuentes por personaje
- **`bibliografia.md`** - Bibliografía consolidada del proyecto
- **`personajes/`** - Listas y referencias cruzadas
  - `namelist.md` - Lista maestra de personajes
  - `namelist_per_section.md` - Personajes organizados por sección DyC
  - `namelist_with_passages.md` - Personajes con referencias bíblicas específicas

### `proyecto/`
Documentación de gestión y control del proyecto.

- **`normativas_biografias.md`** - Reglas y estándares para generación de biografías
- **`auditoria_fuentes_bios.md`** - Control de calidad y auditoría de fuentes
- **`LOTE-PROGRESO.md`** - Seguimiento del primer lote de trabajo
- **`LOTE-PROGRESO-SEGUNDA-PASADA.md`** - Seguimiento de la segunda pasada

### `datos/`
Archivos brutos y datos de contexto utilizados en investigación.

- `batch1_context.txt` - Datos contextuales del primer lote
- `batch2_context.txt` - Datos contextuales del segundo lote  
- `lote1_real.txt` - Datos procesados del primer lote

### `herramientas/`
Scripts y utilidades para procesamiento de datos.

- `get_context.py` - Script para extracción de contexto
- `get_context2.py` - Script alternativo de procesamiento

## 📊 Estadísticas del Proyecto

- **135 biografías completadas** y revisadas
- **138 secciones DyC** con esquemas textuales y gráficos
- **278+ archivos gráficos** entre esquemas y personajes
- **124 fuentes bibliográficas** consolidadas
- **Estructura de 3 niveles máximo** para fácil navegación

## 🔍 Nomenclatura Establecida

- **Biografías**: `Nombre Apellido.md` (ej. `Joseph Smith Jr.md`)
- **Perícopas**: `Esquema de DyC XXX.md` (formato original)
- **Gráficos**: `esquema_dyc_XXX.png` y `personajes_dyc_XXX.png` (formato original)
- **Directorios**: minúsculas con guiones, máximo 3 niveles de anidación
