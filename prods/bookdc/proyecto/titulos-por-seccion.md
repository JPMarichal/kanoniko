## 🎯 Principios para Generación de Títulos

### Criterios Obligatorios
1. **Único**: No repetir títulos existentes
2. **Descriptivo**: Reflejar el contenido principal
3. **Breve**: Máximo 8 palabras preferiblemente
4. **Distintivo**: Fácilmente diferenciable de otros títulos

### Fórmula Recomendada
```
[Sujeto/Concepto Principal] + [Acción/Propósito] + [Contexto si necesario]
```

## 🔍 Proceso de Validación

### Paso 1: Verificar Existencia
- Revisar si la sección ya tiene título histórico
- Consultar perícopas existentes en `contenido/pericopas/`
- Verificar archivos JSON en `contenido/datos/section_summaries/`

### Paso 2: Análisis de Contenido
- Identificar versículos centrales
- Extraer tema principal y subtemas
- Determinar sujeto/acción principal

### Paso 3: Generación
- Aplicar fórmula recomendada
- Asegurar cumplimiento de criterios
- Verificar unicidad contra títulos existentes

### Paso 4: Validación Final
- Confirmar brevedad (≤8 palabras)
- Verificar distintividad
- Aprobar para inclusión en matriz

## 🚫 Restricciones

### Títulos a Evitar
- Genéricos: "Revelación", "Mandamiento", "Profecía"
- Repetitivos: Mismo patrón en múltiples secciones
- Excesivamente largos: Más de 10 palabras
- Confusos: Similares a otros títulos existentes

### Palabras Clave Reservadas
- "Prefacio" (reservado para DyC 1)
- "Palabra de Sabiduría" (reservado para DyC 89)
- "Hoja de Olivo" (si aplica a sección específica)
