---
name: Citar fuentes en FCD, no rutas de archivo
description: Al listar fuentes usadas en una respuesta, usar citación bibliográfica (FCD) en lugar de rutas a archivos del corpus
type: feedback
---

Al presentar las fuentes de una respuesta, usar formato de citación bibliográfica (FCD), no rutas de archivos del corpus.

**Why:** El usuario está interesado en saber *qué* fuentes se usaron de forma legible y citable, no en la ubicación técnica dentro del filesystem. Las rutas son información interna del sistema.

**How to apply:** Cuando el usuario pida fuentes o bibliografía, citar con: título de la obra, autor (si aplica), tipo de publicación (manual, conferencia general, temas de historia, etc.), y fecha. Reservar las rutas de archivo para contexto técnico o de desarrollo.
