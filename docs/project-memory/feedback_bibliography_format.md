---
name: Bibliography as unnumbered "Fuentes citadas"
description: With full FCD citations inline, the bibliography section uses unnumbered bullets ("Fuentes citadas"), not numbered [N] entries.
type: feedback
---

Si las citaciones FCD completas van inline, la sección final del artículo cambia de "Bibliografía y notas" con entradas `[1]...[N]` a **"Fuentes citadas"** con bullets sin numerar.

La sección es una lista de referencia consolidada, no un sistema de llamadas. Incluye tanto las fuentes citadas inline como las fuentes de contexto (obras históricas, seculares, etc.) que no tienen cita inline directa.

**Why:** Los `[N]` numerados en la bibliografía implican un sistema de footnotes que ya no existe si las citaciones completas están en el texto. Mantenerlos crea una incoherencia.

**How to apply:** Al crear o revisar un artículo, usar "## Fuentes citadas" con bullets (`-`) sin numeración.
