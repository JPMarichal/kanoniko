La "Forma T" es un formato de reporte para estudio de escrituras. Estructura:

1. **Título** — tema del estudio
2. **Objetivo** — qué debe aprender o comprender el estudiante
3. **Tabla** con dos columnas:
   - **Concepto** — redacción breve y didáctica; la secuencia de conceptos por sí sola transmite sentido y enseña
   - **Referencia** — cita escritural que respalda el concepto (puede ser versículo único o rango, e.g., Éter 12:6-7)

Los renglones se ordenan didácticamente: leer solo la columna de conceptos ya constituye una lección coherente.

**Why:** El usuario diseñó este formato para estudio de escrituras. Ya lo explicó una vez y no se guardó — no debe repetirse.

**How to apply:** Cuando el usuario pida una "Forma T" o un estudio temático en este formato, generar la tabla con conceptos breves que formen una secuencia de aprendizaje, cada uno respaldado por su referencia escritural.

**Usos derivados:** La Forma T no es un producto final — es una base que alimenta:
- Artículos y discursos (la secuencia didáctica da el esqueleto)
- Materiales de estudio (lecciones, presentaciones)
- Nuevas relaciones para la KG (cada fila concepto→referencia puede generar relaciones DEFINES/ILLUSTRATES)

Reglas clave:
- **Exhaustiva**: buscar en TODAS las escrituras disponibles (todos los volúmenes del corpus), no solo las más obvias. Si el tema aparece en Génesis, Apocalipsis, Alma y D&C, todos deben estar.
- **Acotada en tema**: el tema debe ser lo más específico posible para que la exhaustividad sea manejable.
- **No granular**: usar rangos de versículos (e.g., Alma 42:2-6), no verso a verso. Agrupar cuando el pasaje desarrolla una sola idea.
- **Concepto > cita**: cada fila captura una idea, no un versículo. Varios versículos pueden respaldar una sola idea como rango.
