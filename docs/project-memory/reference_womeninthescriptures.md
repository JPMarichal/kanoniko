## Women in the Scriptures — womeninthescriptures.com

**Author:** Heather Farrell, BYU (Public Health), doula, 3 books via Cedar Fort Publishing. Active LDS member, 12+ years running the site.

**Content:** 876 total posts; ~75+ named woman profiles across OT, NT, BoM, D&C, PoGP, plus thematic essays on priesthood, motherhood, Relief Society, feminism, temple, etc.

**Profile structure:** Facts → Speculations → Author's Thoughts → Questions to Think About. ~2500-3000 words each. Heavy scripture references with hyperlinks.

**Platform:** WordPress (migrated from Blogger). URL pattern: `/YYYY/MM/slug.html`

**Copyright:** "Copyright 2019 - Women In The Scriptures" — standard copyright, no Creative Commons. Contact: womeninthescriptures.com/contact-us

**Sitemap:** `wp-sitemap-posts-post-1.xml` has all 876 post URLs with lastmod dates.

**Authority model classification:**
- Authority: 20 (independent LDS scholarship)
- Rigor: 50 (researched, scripture-heavy, not peer-reviewed)
- Importance: Interesante (high pedagogical value)
- Official: false
- Current: true

**Corpus path:** `corpus/en/web/womeninthescriptures/`

**Filtering needed:** Many posts are personal (giveaways, "Five Things for Friday", birth stories, homeschool, book promos). Only woman profiles and substantive scripture essays should enter the corpus.

**Index pages with profile lists:**
- `/old-testamen` (43 women)
- `/new-testament-women` (22 women)
- `/book-of-mormon-women` (8 listed, 87 documented total)
- `/d-women` (D&C)
- `/pearl-of-great-price-women`

**Category taxonomy:** `/p/women-in-the-scriptures/{volume}` and `/p/topics/{topic}` (25+ topics)
