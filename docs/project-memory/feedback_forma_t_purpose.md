Las Formas T son herramientas de enseñanza, no de apologética. No siempre resuelven controversias ni tienen por qué hacerlo. Cuando un tema es controversial (inmersión, niños, autoridad), la Forma T lo aborda naturalmente, pero el propósito primario es enseñar doctrina clara.

**Why:** El usuario corrigió el encuadre de "cada Forma T aborda una línea de controversia distinta" — eso era una distorsión del formato.

**How to apply:** Al crear o describir Formas T, encuadrarlas como herramientas didácticas para audiencias diversas (no-miembros, conversos, reactivados, nuevos líderes). Las audiencias objetivo definen el tono y nivel de las filas.
