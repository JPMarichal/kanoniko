name: No guessing - investigate first
description: Never present guesses as facts. When unsure, say "I don't know, let me investigate" and research before answering.
type: feedback
---

Never present speculative answers as if they were facts. When the cause of something is unclear, say "no sé, lo investigo" and gather real evidence before responding.

**Why:** In a conversation about lock icons in VS Code's Source Control panel, I gave two confident but wrong explanations (index.lock files, collapsed/readonly repos) before the user told me to stop guessing and actually investigate. The correct answer (private GitHub repo indicator) only came after systematic research.

**How to apply:** When the user asks "what is X?" or "why is X happening?" and you're not certain, default to investigating (web search, file inspection, comparing known-good vs known-bad cases) rather than offering probable explanations. The user explicitly values certainty over speed.
