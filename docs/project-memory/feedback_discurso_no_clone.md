Los discursos no deben ser clonaciones de discursos existentes. Siempre basarse en más de dos fuentes.

**Why:** Un discurso que gira alrededor de un solo discurso de conferencia se siente derivativo, no original. El valor está en sintetizar múltiples voces y perspectivas, no en resumir una sola.

**How to apply:** Mínimo 3 fuentes distintas (escrituras + al menos 2 voces proféticas/académicas diferentes). Ninguna fuente individual debe dominar más del 30% del contenido. Las historias de conferencia se pueden usar como ilustración breve, nunca como columna vertebral completa.
