La senda de los convenios tiene una arquitectura completa de 8 colecciones:

```
Senda (8) → Bautismo (8) → Espíritu Santo (7) → Santa Cena (8) → Sacerdocio (11) → Investidura (6) → Sellamiento (5)
  intro       entrada       don/compañía       renovación semanal   autoridad      convenios templo    familia eterna
```

+ **Vidas** (6) — colección biográfica complementaria (Melquisedec, Pedro, Santiagos, Juan)

**Totales:** 59 formas T — 53 en la senda (incluyendo intro) + 6 vidas.

**Why:** Las colecciones no son temas independientes. Cada una construye sobre la anterior y prepara la siguiente. El orden refleja la progresión doctrinal real que vive un miembro. La colección introductoria establece el marco conceptual (qué es una ordenanza, qué es un convenio, por qué importan).

**How to apply:**
- La colección `senda-de-los-convenios` es prerequisito conceptual de todas las demás.
- La Santa Cena es el mecanismo de renovación entre confirmación y sacerdocio.
- La forma `santa-cena-oficios-sacerdocio` está integrada como forma 8 de la colección santa-cena.
- Las **vidas** son un género diferente: biografías complementarias, no parte de la senda.
- Todas las formas tienen collection y collection_order; no quedan huérfanas.
