La senda de los convenios tiene una arquitectura de 6 colecciones doctrinales en secuencia:

```
Bautismo (8) → Espíritu Santo (7) → [Santa Cena] → Sacerdocio (11) → Investidura (6) → Sellamiento (5)
  entrada       don/compañía      renovación semanal   autoridad      convenios templo    familia eterna
```

**Why:** Las colecciones no son temas independientes. Cada una construye sobre la anterior y prepara la siguiente. El orden refleja la progresión doctrinal real que vive un miembro.

**How to apply:**
- La Santa Cena es la pieza que falta — va entre confirmación y sacerdocio como mecanismo de renovación.
- La forma huérfana `santa-cena-oficios-sacerdocio` es técnica/administrativa; pertenece más a sacerdocio o se reescribe dentro de una colección propia.
- Las **vidas** (Melquisedec, Pedro, Santiagos, Juan) son un género diferente: biografías complementarias, no parte de la senda.
- Total actual: 44 formas T (37 en la senda + 6 vidas + 1 huérfana).
- Al crear la colección de Santa Cena, el total de la senda subirá a 37 + nuevas formas.
