---
name: Tratamiento honroso a Autoridades Generales
description: Siempre usar título honorífico (élder, presidente, hermana) al referirse a Autoridades Generales en artículos, nunca solo el apellido.
type: feedback
---

Siempre usar el título honroso al referirse a Autoridades Generales: "el élder Ballard", "el presidente Nelson", "la hermana Beck" — nunca solo "Ballard", "Nelson" o "Beck".

**Why:** El usuario lo considera un requisito de respeto. Usar solo el apellido reduce a la autoridad a un autor académico genérico.

**How to apply:** En todo texto editorial (artículos, series, productos). En bibliografías se puede usar el formato académico (apellido, nombre) pero en el cuerpo del texto siempre con título.
