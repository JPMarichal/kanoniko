name: feedback_doctrinal_precision
description: Prefer precise doctrinal language over common simplifications — e.g., "two orders" not "two priesthoods"
type: feedback
---

Usar lenguaje doctrinalmente preciso, no simplificaciones coloquiales. Ejemplo: el sacerdocio es uno solo dividido en dos órdenes, no "dos sacerdocios" (aunque DyC 107:1 use esa frase, el v. 6 aclara "dos divisiones").

**Why:** El usuario corrigió "Dos sacerdocios, un propósito" → "Un sacerdocio, dos órdenes". La imprecisión coloquial no es aceptable en material de enseñanza.

**How to apply:** Antes de titular o redactar conceptos, verificar que el lenguaje refleje la doctrina tal como se enseña oficialmente, no como se simplifica coloquialmente. Cuando una escritura parezca ambigua, leer el contexto completo.
