Siempre consultar el corpus local (Alejandría, KBA) antes de recurrir a web search.

**Why:** El corpus tiene 24,000+ documentos indexados incluyendo el Manual General completo (EN/ES), conferencias generales, escrituras, y materiales de estudio. El usuario señaló que sin este orden, carece de sentido tener corpus, KBA e índices.

**How to apply:** Seguir el skill `documentation-first` (en `~/.claude/skills/documentation-first/SKILL.md`) que define el protocolo completo: clasificar pregunta → corpus primero → evaluar cobertura → web solo como complemento.
