## Contenido clave
- 6 escrituras ancla para gobierno por consejos (DyC 88:122, 107:27, 38:27, 102:1-3, Hechos 15, 1 Cor 14:26)
- 3 escrituras para revelación colectiva (DyC 9:8-9, Moroni 7:13, 3 Nefi 11:28-30)
- 3 escrituras para hogar como centro (DyC 68:25-28, DyC 109:8, Alma 53:20-21)
- 2 escrituras para mujeres y autoridad (DyC 25:3,7; DyC 107:5)
- 3 escrituras para Restauración/Segunda Venida (Efesios 1:10, Hechos 3:21, DyC 128:21)
- Fuentes proféticas diversificadas por artículo (Stephen L Richards, Christofferson, Hinckley, Oaks, José Smith, Joseph F. Smith)
- Redistribución del tema mujeres: concentrar en Art 04, máximo 1-2 oraciones de referencia cruzada en los demás

**Why:** Los artículos actuales tienen cero escrituras y repiten las mismas 3-4 citas proféticas. Son crónicas administrativas sin profundidad espiritual.

**How to apply:** Al reescribir cada artículo, usar la tabla de escrituras y fuentes correspondiente. Patrón texto-contexto-aplicación para cada cambio administrativo.
