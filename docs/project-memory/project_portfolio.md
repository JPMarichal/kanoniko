After Phase 5 closure, monolithic "Phase 6" was decomposed into 9 independent projects in `proj/` directory. Each has `01-requirements.md` and `02-project-plan.md`.

**Why:** Sequential phases don't fit when work is parallelizable and priorities shift based on usage feedback.

**How to apply:** When starting new work, check `proj/README.md` for priority order and `proj/00-backlog.md` for selection criteria. Update status in README as projects progress.

Priority tiers:
- **Highest**: P1 Scripture Structure (long chain: divisions, parts, pericopes)
- **High**: P2 Scripture Refresh, P3 ETL Templates, P4 Corpus Expansion
- **Medium**: P5 Chat Client UI, P6 Advanced Relations, P7 Deep Disambiguation
- **Lower**: P8 Synthesis Engine, P9 Fine-Tuning
