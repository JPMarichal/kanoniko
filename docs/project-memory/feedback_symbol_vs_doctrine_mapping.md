No toda imagen o símbolo bíblico mapea directamente a un concepto de la Restauración. Verificar la conexión doctrinal real antes de incluir una referencia.

**Why:** Se propuso agregar Isaías 22:22 y Apocalipsis 3:7 (llave de David) a la forma T de llaves del sacerdocio. El usuario señaló correctamente que la llave de David es un símbolo cristológico/mesiánico, no una referencia a las llaves del sacerdocio como autoridad administrativa.

**How to apply:** Cuando una palabra clave (llave, sello, poder, etc.) aparezca en la Biblia, leer el contexto para determinar si el uso es análogo o simplemente homónimo antes de citarlo como referencia doctrinal.
