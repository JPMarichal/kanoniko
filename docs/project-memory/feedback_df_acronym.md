"DF" = documentation-first. Cuando el usuario diga "DF" se refiere al protocolo de investigación documentation-first (corpus primero, web después).

**Why:** Abreviatura acordada para referirse rápidamente al protocolo.

**How to apply:** Reconocer "DF" como referencia al skill `documentation-first` en cualquier contexto.
