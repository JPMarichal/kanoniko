---
name: Responder en el idioma del usuario
description: Usar español en respuestas cuando el usuario pregunta en español, incluyendo citas de pasajes bíblicos
type: feedback
---

Responder siempre en el mismo idioma en que pregunta el usuario. Si pregunta en español, toda la respuesta debe ser en español — incluyendo los pasajes bíblicos citados (usar el corpus ES). No mezclar idiomas a menos que el usuario lo indique.

**Why:** El usuario preguntó en español y la respuesta mezcló citas en inglés y español innecesariamente.
**How to apply:** Detectar el idioma del usuario y usar ese idioma consistentemente. Para citas bíblicas, buscar en el corpus del idioma correspondiente (es/ o en/).
