# Para los facilitadores

Gracias por prestar servicio como facilitador de un grupo de autosuficiencia. El grupo debe funcionar como un consejo teniendo como maestro al Espíritu Santo. Su función es ayudar a cada persona a sentirse cómoda al compartir ideas, los éxitos y los fracasos.

+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+
| Qué hacer                                                                         | Qué evitar                                                                                                         |
+===================================================================================+====================================================================================================================+
| Antes de cada reunión                                                                                                                                                                                  |
+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+
| - Descargar los videos del sitio srs.lds.org/videos.                              | - Preparar una lección.                                                                                            |
|                                                                                   |                                                                                                                    |
| - Verificar que el equipo de video funcione.                                      | - Cancelar las reuniones. Si no puede asistir, pida a un miembro del grupo que sea el facilitador en vez de usted. |
|                                                                                   |                                                                                                                    |
| - Repasar el capítulo brevemente.                                                 |                                                                                                                    |
|                                                                                   |                                                                                                                    |
| - Prepararse espiritualmente.                                                     |                                                                                                                    |
+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+
| Durante cada reunión                                                                                                                                                                                   |
+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+
| - Comenzar y terminar a tiempo.                                                   | - Enseñar o actuar como el experto.                                                                                |
|                                                                                   |                                                                                                                    |
| - Procurar que todos den un informe, incluso los que hayan llegado tarde.         | - Hablar más que los demás.                                                                                        |
|                                                                                   |                                                                                                                    |
| - Elegir a alguien para que controle el tiempo.                                   | - Responder todas las preguntas.                                                                                   |
|                                                                                   |                                                                                                                    |
| - Instar a todos a participar.                                                    | - Ser el centro de atención.                                                                                       |
|                                                                                   |                                                                                                                    |
| - Ser parte del grupo. Hacer compromisos, cumplirlos e informar de ellos.         | - Sentarse en la cabecera de la mesa.                                                                              |
|                                                                                   |                                                                                                                    |
| - Divertirse y celebrar el éxito.                                                 | - Ponerse de pie para dirigir como el facilitador.                                                                 |
|                                                                                   |                                                                                                                    |
| - Confiar en el cuaderno de ejercicios y seguirlo.                                | - Saltarse la sección “Meditar”.                                                                                   |
|                                                                                   |                                                                                                                    |
|                                                                                   | - Dar su opinión después de cada comentario.                                                                       |
+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+
| Después de cada reunión                                                                                                                                                                                |
+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+
| - Comunicarse con los integrantes del grupo durante la semana y animarlos.        | - Olvidarse de mantener al corriente al especialista de estaca en autosuficiencia en cuanto al progreso del grupo. |
|                                                                                   |                                                                                                                    |
| - Evaluarse a sí mismo usando la “Autoevaluación para el facilitador” (página V). |                                                                                                                    |
+-----------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------+

## Importante: Informar y mejorar

- Complete el formulario Inscripción de grupo en su primera reunión y el formulario Informe de finalización de grupo y solicitud de certificado en la última. Visite srs.lds.org/report.

- Revise el manual Cómo ser facilitador de grupos en srs.lds.org/facilitator.AUTOEVALUACIÓN PARA EL FACILITADOR

##

Después de cada reunión del grupo, repase las siguientes declaraciones. ¿Qué tan bien se desempeña?
