| Menos útil                                                                                                                                         | Más útil                                                                          |
|                                                                                                                                                    |                                                                                   |
| - “Sé exactamente cómo te sientes”.                                                                                                                | - “No sé qué decirte en este momento, pero me alegro de que me lo hayas contado”. |
|                                                                                                                                                    |                                                                                   |
|   - Aunque hayamos pasado por algo muy similar, siempre es mejor hacer preguntas y escuchar cómo se siente la persona.                             | - “Háblame de lo que sientes ahora”.                                              |
|                                                                                                                                                    |                                                                                   |
| - “Solamente debes tener fe; todo saldrá bien”.                                                                                                    | - “Te aprecio mucho”.                                                             |
|                                                                                                                                                    |                                                                                   |
|   - Por supuesto que debemos tener fe, pero eso no cambia el hecho de que algo resulte doloroso o no. Es importante estar presente con la persona. | - “Puedes contar conmigo”.                                                        |
|                                                                                                                                                    |                                                                                   |
| - “Al menos tú…”.                                                                                                                                  | - “Es normal sentirse así”.                                                       |
|                                                                                                                                                    |                                                                                   |
|   - Cuando comenzamos las frases con “al menos”, minimizamos lo que la persona está viviendo.                                                      |                                                                                   |
|                                                                                                                                                    |                                                                                   |
| - “Dios tiene un plan”.                                                                                                                            |                                                                                   |
|                                                                                                                                                    |                                                                                   |
|   - Esto puede dar la impresión de que intentamos resolver rápidamente el problema, en lugar de realmente escuchar y amar.                         |                                                                                   |
|                                                                                                                                                    |                                                                                   |
| - “Ellos están en un lugar mejor”.                                                                                                                 |                                                                                   |
|                                                                                                                                                    |                                                                                   |
|   - Decir esto no hace que la persona deje de echar de menos a su ser querido.                                                                     |                                                                                   |
