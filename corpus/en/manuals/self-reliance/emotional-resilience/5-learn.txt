## 6. Ways to Offer Help

+------------------------------------------------------------------------------------------------------------------------------------------------+----------------------------------------------------------------------+
| Less Helpful                                                                                                                                   | More Helpful                                                         |
+================================================================================================================================================+======================================================================+
| Less Helpful                                                                                                                                   | More Helpful                                                         |
|                                                                                                                                                |                                                                      |
| - “I know exactly how you feel.”                                                                                                               | - “I don’t know what to say right now, but I’m so glad you told me.” |
|                                                                                                                                                |                                                                      |
|   - Even if we have been through something very similar, it is always better to ask questions and listen to how the person feels.              | - “Tell me about what you’re feeling right now.”                     |
|                                                                                                                                                |                                                                      |
| - “Just have faith; everything will work out.”                                                                                                 | - “I care about you.”                                                |
|                                                                                                                                                |                                                                      |
|   - Of course we should have faith, but that doesn’t change whether something is painful or not. It’s important to be present with the person. | - “I’m here for you.”                                                |
|                                                                                                                                                |                                                                      |
| - “At least you …”                                                                                                                             | - “It’s OK to feel this way.”                                        |
|                                                                                                                                                |                                                                      |
|   - When we start sentences with “at least,” we minimize what the person has been through.                                                     |                                                                      |
|                                                                                                                                                |                                                                      |
| - “God has a plan.”                                                                                                                            |                                                                      |
|                                                                                                                                                |                                                                      |
|   - This can sound like we are trying to quickly solve the problem instead of really listening and loving.                                     |                                                                      |
|                                                                                                                                                |                                                                      |
| - “They’re in a better place.”                                                                                                                 |                                                                      |
|                                                                                                                                                |                                                                      |
|   - Saying this doesn’t make the person miss his or her loved one any less.                                                                    |                                                                      |
